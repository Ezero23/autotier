# AutoTier v0.1.4

> Shadow 路由观测台 — 候选解析、可再次导入 legacy、可选图片助手

**[English →](v0.1.4-en.md)**

---

## 概述

AutoTier v0.1.4 是 v0.1.3 之上的 Shadow-only 补丁：收口装机验收里发现的候选为空与 legacy 导入入口消失，并加入可选图片助手。Live 路由、Policy Hint、Canary 仍留待 v0.2+。

**发布日期**：2026-08-24

**范围**：仅 Shadow 观测。开启图片助手时可能把图片块改写成文字描述，但**不会**更改出站模型或 Provider。

---

## 亮点

- **候选解析**：推荐的 Cheap / Mid / Strong 槽位会从已保存 Provider 槽位填入 `candidate_provider` / `candidate_model`
- **Legacy 导入**：首次启动创建 `~/.autotier/autotier.db` 后，只要仍有 `~/.cc-switch`，一键复制导入入口仍然可见
- **图片助手**（默认关闭）：当前模型明确不看图时，先用已声明的视觉模型转成文字；失败则原样转发
- **身份收口**：Issue 模板、CODEOWNERS、Windows 深链文档指向 AutoTier 而非上游 CC Switch

---

## Shadow 不变量（v0.1 合同）

```text
autotier_mutated_request == false
actual_outbound_model    == baseline_outbound_model
actual_outbound_provider == baseline_outbound_provider
```

图片助手生效时，决策记录 `vision_fallback_applied`。它不把 `autotier_mutated_request` 置为 true，也不做出站模型 / Provider 切换。

Off 模式零决策；Shadow 仍不执行候选。

---

## 从 v0.1.3 升级

1. 从 [Releases](https://github.com/Ezero23/autotier/releases) 安装 v0.1.4。
2. 确认 Provider 槽位仍有 Cheap / Mid / Strong 模型 ID，再发一条 Shadow 请求，检查决策详情中的候选模型已填写。
3. 若仍有 `~/.cc-switch`，即使 AutoTier 已自建数据库，路由设置里也应还能看到 legacy 导入横幅。
4. 不需要图转文时请保持图片助手关闭。

---

## 已知限制（v0.1）

- 验证客户端：**Claude Code**
- macOS 未签名 zip（无 DMG）；Gatekeeper / SmartScreen 需手动放行
- 无 Live 路由或自动切模型
- 图片助手不对未知模型能力做猜测
