# AutoTier v0.1.0

> Shadow 路由观测台 — 记录候选决策，不改变真实出站模型与 Provider

**[English →](v0.1.0-en.md)**

---

## 概述

AutoTier v0.1.0 是基于 CC Switch 代理基座的首个可安装版本。Claude Code 请求经过本地代理时，可记录路由决策、Usage 关联与成本投影，同时在 Shadow 模式下**保证**不修改出站请求、模型或 Provider。

**发布日期**：2026-08-20

**范围**：仅 Shadow 观测。Live 路由、Policy Hint、Canary 留待 v0.2+。

---

## 亮点

- **Shadow 模式**：生成候选 Slot 推荐与决策记录，且 `autotier_mutated_request == false`
- **Provider Slots**：四语义槽位（Strong / Balanced / Cheap / Fallback）及 per-provider 配置
- **决策 UI**：列表 / 详情 / 标注 / 筛选 / 分页，四语言文案
- **隐私安全导出**：JSONL + manifest，含密钥扫描；默认不含原文 Prompt
- **Replay 与 Eval**：Session holdout 指标与离线回放引擎
- **独立产品身份**：`AutoTier`、`com.ezero.autotier`、数据目录 `~/.autotier`
- **Legacy 迁移**：检测 `~/.cc-switch` 并支持仅复制导入，不修改 legacy 数据库

---

## Shadow 不变量（v0.1 合同）

```text
autotier_mutated_request == false
actual_outbound_model    == baseline_outbound_model
actual_outbound_provider == baseline_outbound_provider
```

Off 模式零决策；Shadow 模式不增加上游网络调用。

---

## 数据与隐私

- 默认数据库：`~/.autotier/autotier.db`
- Legacy 回退：尚无 AutoTier DB 时继续读取 `~/.cc-switch/cc-switch.db`
- 默认不持久化原始 Prompt / System Prompt / Tool Result
- 导出前扫描密钥

## 从 CC Switch 升级

若已有 `~/.cc-switch` 安装，在导入 `~/.autotier` 前 AutoTier 会继续读取 legacy 目录。可在「路由设置」面板使用 legacy 导入横幅进行仅复制迁移。
