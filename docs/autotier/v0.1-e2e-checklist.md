# AutoTier v0.1 — 全新安装 E2E 验收清单（10A）

> 14 步手动验收。在干净用户环境执行（无 `~/.autotier`、无既有 AutoTier DB）。每步记录 Pass/Fail 与截图/日志路径。

**前置**：已安装 AutoTier v0.1.0 构建；Claude Code 可用；至少一个 Anthropic 兼容 Provider 可连。

**自动化验收**：运行 `bash scripts/verify-v0.1-release.sh`，结果写入 `docs/autotier/v0.1-e2e-automation-results.md`。
