# AutoTier v0.1.4

> Shadow routing observatory — candidate resolution, reachable legacy import, optional vision copilot

**[中文版 →](v0.1.4-zh.md)**

---

## Overview

AutoTier v0.1.4 is a Shadow-only patch on v0.1.3. It finishes the installed-app gaps found in v0.1.3 validation and adds an opt-in vision copilot. Live routing, Policy Hint, and Canary remain deferred to v0.2+.

**Release date**: 2026-08-24

**Scope**: Shadow observation. Vision copilot may rewrite image blocks into text when enabled; it never changes the outbound model or provider.

---

## Highlights

- **Candidate resolution**: recommended Cheap / Mid / Strong slots now fill `candidate_provider` and `candidate_model` from the saved Provider slot
- **Legacy import**: the copy-only `~/.cc-switch` import action stays visible after first launch creates `~/.autotier/autotier.db`
- **Vision copilot** (off by default): when the current model is explicitly text-only, a declared vision model describes images first; failures fall back to the original request
- **Identity follow-through**: issue templates, CODEOWNERS, and Windows deep-link docs use AutoTier rather than CC Switch

---

## Shadow invariants (v0.1 contract)

```text
autotier_mutated_request == false
actual_outbound_model    == baseline_outbound_model
actual_outbound_provider == baseline_outbound_provider
```

Vision copilot, when applied, records `vision_fallback_applied` on the decision. It does not flip `autotier_mutated_request` and does not change outbound model or provider.

Off mode writes zero decisions. Shadow mode still does not execute the candidate.

---

## Upgrade from v0.1.3

1. Install the v0.1.4 build from [Releases](https://github.com/Ezero23/autotier/releases).
2. Confirm Provider slots still have Cheap / Mid / Strong model IDs, then send a Shadow request and check the decision detail for a filled candidate model.
3. If you still have `~/.cc-switch`, Routing settings should show the legacy import banner even after AutoTier has created its own database.
4. Leave vision copilot off unless you want text-only models to receive image descriptions.

---

## Known limitations (v0.1)

- Validated client: **Claude Code**
- Unsigned macOS zip (no DMG); Gatekeeper / SmartScreen require a manual allow
- No Live routing or automatic model switching
- Vision copilot never guesses unknown model capabilities
