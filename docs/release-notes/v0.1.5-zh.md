# AutoTier v0.1.5

> Shadow 路由观测台 — AutoTier 菜单栏图标与产品名收口

**[English →](v0.1.5-en.md)**

---

## 概述

AutoTier v0.1.5 是 v0.1.4 之上的 Shadow-only 身份补丁：macOS 菜单栏改为 AutoTier 三层标记，并清掉剩余 CC Switch 产品名。Live 路由、Policy Hint、Canary 仍留待 v0.2+。

**发布日期**：2026-08-24

**范围**：仅 Shadow 观测。不更改出站模型或 Provider。

---

## 亮点

- **菜单栏图标**：macOS 托盘 template 使用 AutoTier 三层路由标记，不再用上游 CC Switch 星形
- **运行时名称**：开机自启与 Claude Desktop profile 名称均为 AutoTier
- **文档**：贡献、安全、支持与路由指南改称 AutoTier
- **Legacy 导入不变**：首次启动后仍可从 `~/.cc-switch` 只读复制导入

---

## Shadow 不变量（v0.1 合同）

```text
autotier_mutated_request == false
actual_outbound_model    == baseline_outbound_model
actual_outbound_provider == baseline_outbound_provider
```

---

## 从 v0.1.4 升级

1. 从 [Releases](https://github.com/Ezero23/autotier/releases) 安装 v0.1.5。
2. 确认菜单栏 / 托盘图标是 AutoTier 三层标记，而不是 12 瓣星。
3. legacy `~/.cc-switch` 导入、图片助手（默认关闭）以及 Shadow 候选字段行为与 v0.1.4 相同。

---

## 已知限制（v0.1）

- 验证客户端：**Claude Code**
- macOS 未签名 zip（无 DMG）；Gatekeeper / SmartScreen 需手动放行
- 无 Live 路由或自动切模型
