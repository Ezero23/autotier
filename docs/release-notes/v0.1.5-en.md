# AutoTier v0.1.5

> Shadow routing observatory — AutoTier menubar icon and product-name cleanup

**[中文版 →](v0.1.5-zh.md)**

---

## Overview

AutoTier v0.1.5 is a Shadow-only identity patch on v0.1.4. The macOS menu bar icon now uses the AutoTier three-tier mark, and leftover CC Switch product names in runtime and docs are replaced. Live routing, Policy Hint, and Canary remain deferred to v0.2+.

**Release date**: 2026-08-24

**Scope**: Shadow observation. No change to outbound model or provider.

---

## Highlights

- **Menu bar icon**: macOS tray template is the AutoTier three-tier routing mark, not the upstream CC Switch asterisk
- **Runtime names**: login-item name and Claude Desktop profile name are AutoTier
- **Docs**: contributor, security, support, and routing guides say AutoTier
- **Legacy import unchanged**: copy-only `~/.cc-switch` import stays available after first launch

---

## Shadow invariants (v0.1 contract)

```text
autotier_mutated_request == false
actual_outbound_model    == baseline_outbound_model
actual_outbound_provider == baseline_outbound_provider
```

---

## Upgrade from v0.1.4

1. Install the v0.1.5 build from [Releases](https://github.com/Ezero23/autotier/releases).
2. Confirm the menu bar / tray glyph is the AutoTier stacked-tier mark, not the 12-ray asterisk.
3. Legacy `~/.cc-switch` import, vision copilot (off by default), and Shadow candidate fields behave as in v0.1.4.

## Known limitations (v0.1)

- Validated client: **Claude Code**
- Unsigned macOS zip (no DMG); Gatekeeper / SmartScreen require a manual allow
- No Live routing or automatic model switching
