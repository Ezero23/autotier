# AutoTier v0.1.0

> Shadow routing observatory — observe candidate decisions without changing outbound model or provider

**[中文版 →](v0.1.0-zh.md)**

---

## Overview

AutoTier v0.1.0 is the first installable release of the local-first Shadow routing product built on the CC Switch proxy foundation. Every Claude Code request can pass through a local proxy that records routing decisions, usage linkage, and cost projections — while **guaranteeing** that Shadow mode never mutates the outbound request, model, or provider.

**Release date**: 2026-08-20

**Scope**: Shadow observation only. Live routing, Policy Hint, and Canary are deferred to v0.2+.

---

## Highlights

- **Shadow mode**: Generates candidate slot recommendations and decision records with `autotier_mutated_request == false`
- **Provider slots**: Four semantic slots (Strong / Balanced / Cheap / Fallback) with per-provider configuration
- **Decision UI**: List, detail, labels, filters, pagination, and four-locale copy
- **Privacy-safe export**: JSONL + manifest with secret scanning; no raw prompt by default
- **Replay & eval**: Session holdout metrics and replay engine for offline analysis
- **Independent identity**: Product name `AutoTier`, bundle id `com.ezero.autotier`, data dir `~/.autotier`
- **Legacy migration**: Detect and copy-only import from `~/.cc-switch` without touching the legacy database

---

## Shadow invariants (v0.1 contract)

```text
autotier_mutated_request == false
actual_outbound_model    == baseline_outbound_model
actual_outbound_provider == baseline_outbound_provider
```

Off mode writes zero decisions. Shadow mode adds no extra upstream network calls.

---

## Data & privacy

- Default database path: `~/.autotier/autotier.db`
- Legacy fallback: reads `~/.cc-switch/cc-switch.db` when no AutoTier DB exists yet
- No raw prompt / system prompt / tool result persisted by default
- Export bundle scans for secrets before write

## Known limitations (v0.1)

- Validated client: **Claude Code** (core types are agent-agnostic; Claude parsing uses an adapter)
- No Live routing or automatic model switching
- No cloud telemetry
- Three-platform signed builds require maintainer release workflow (`git tag v0.1.0`)

---

## Upgrade from CC Switch

If you have an existing `~/.cc-switch` installation, AutoTier continues reading it until you import into `~/.autotier`. Use the legacy import banner in Routing settings for a copy-only migration.
