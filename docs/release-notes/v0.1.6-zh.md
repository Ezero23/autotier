> Shadow 路由观测台 — 任务控制台与安全发布链路

**[English →](v0.1.6-en.md)**

---

## 概述

AutoTier v0.1.6 将原有代理设置页重构为面向任务的三层控制台，并收紧正式发布流程。用户可以从概览、Shadow 结果、接入与高级三个入口理解当前状态、复核候选决策并完成 Agent 接入。

**发布日期**：待 GitHub Release 发布时确定

**范围**：仅 Shadow 观测。不更改出站模型、Provider 或用户现有请求。

---

## 亮点

- **概览面板**：集中显示本地代理、Agent 接入、真实 Shadow 决策、候选配置、候选分布、完成与复核数量，并给出唯一推荐下一步。
- **Shadow 结果中心**：保留决策列表、Cheap/Mid/Strong 建议、筛选、人工标注、Replay、Eval、导出和推荐原因说明。
- **三步接入流程**：启动本地代理、配置 Agent 使用 AutoTier 端点、发送真实任务并观察 Shadow。
- **高级设置收敛**：路由配置、Failover、整流器和全局代理默认折叠，避免首次使用时造成信息过载。
- **发布流程收紧**：正式版本必须提供 Tauri updater 签名密钥；构建缺少签名时会失败，不再发布空的 `latest.json`。
- **更新清单校验**：`latest.json` 在上传前强制验证 macOS、Windows x64/ARM64 与 Linux x64/ARM64 的签名条目。

## 从 v0.1.5 升级

1. 从 [Releases](https://github.com/Ezero23/autotier/releases) 安装 v0.1.6。
2. 在“概览”确认本地代理、Agent 接入与候选配置状态。
3. 通过“接入与高级”完成三步接入；需要时再展开高级配置。
4. 在 Shadow 结果中心积累并复核真实任务样本。

---

## 已知限制

- v0.1.6 仍不开放 Canary、Live 自动切模或自动升降档。
- 真实 Shadow 样本仍需继续积累，不能仅凭少量样本开启自动路由。
- 跨 Provider 切换、额度 Policy Hint 与 Potluck Monitor 集成不属于本版本范围。
- macOS Gatekeeper、Windows SmartScreen 以及 Apple 公证状态取决于对应发布凭据是否配置完整。
